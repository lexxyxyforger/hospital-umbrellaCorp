# 🔴 RS Umbrella Corp — Sistem Informasi Medis

Portal layanan medis resmi **Umbrella Corporation** — dibangun di atas [Next.js](https://nextjs.org) dengan standar teknologi kelas korporasi.

## Memulai

Jalankan server pengembangan:

```bash
npm run dev
# atau
yarn dev
# atau
pnpm dev
# atau
bun dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser untuk mengakses portal RS Umbrella Corp.

Mulai edit halaman utama dengan memodifikasi `app/page.tsx`. Perubahan akan langsung tercermin secara otomatis.

## Struktur Proyek

- `app/page.tsx` — Halaman utama portal RS Umbrella Corp
- `lib/data.ts` — Data dokter, layanan, dan artikel Umbrella Corp
- `components/` — Komponen UI sistem medis
- `app/globals.css` — Gaya global berstandar Umbrella Corp

## Teknologi

Proyek ini menggunakan [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) untuk optimasi tipografi otomatis, serta stack modern yang memenuhi standar infrastruktur digital Umbrella Corporation.
